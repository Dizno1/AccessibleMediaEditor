ACCESSIBLE MEDIA EDITOR BUILD 0.3.1 TESTING GUIDE

PURPOSE OF THIS BUILD

Build 0.3.1 uses a direct-edit-first workflow, repairs the native window title, reduces playhead announcement noise, and adopts the shared Open Door editing shortcuts. Projects remain optional.

FIRST TEST

1. Start the application. Focus should be on Open Media.
2. Press Ctrl+O and open one short video or audio file.
3. Confirm that the filename becomes both the main heading and the Windows application title.
4. Press Ctrl+Page Down repeatedly with the JAWS Virtual Cursor off.
5. Confirm that focus moves through Media, Playback, Edit, and Output, then returns to Media.
6. Within each section, press Tab to move through its controls.
7. Confirm that durations are announced as hours, minutes, seconds, and milliseconds rather than decimal seconds.
8. Start playback while focus remains on the playhead. Confirm that JAWS does not announce every automatic time update.

MULTIPLE MEDIA TEST

1. Press Ctrl+O.
2. Select several files in the Windows Open Media dialog, or paste several files copied from File Explorer.
3. Enter the Open media list and turn the JAWS Virtual Cursor off.
4. Use plain Up Arrow and Down Arrow to select files.
5. Use Ctrl+Up Arrow and Ctrl+Down Arrow to rearrange the selected file.

PRECISE EDITING

- Ctrl+P previews the selected video or audio.
- Escape stops playback or closes an editing dialog.
- U and I scrub backward and forward by one second.
- Shift+U and Shift+I scrub by 100 milliseconds.
- Ctrl+Shift+U and Ctrl+Shift+I scrub by 10 milliseconds.
- Left bracket sets the In mark.
- Right bracket sets the Out mark.
- Left Arrow and Right Arrow move by five seconds.
- Shift+Left Arrow and Shift+Right Arrow move by 30 seconds.
- J and L move by five minutes.
- Alt+Left Arrow and Alt+Right Arrow move by one millisecond.
- Home and End move to the beginning and end.
- Ctrl+G opens separately labeled Hours, Minutes, Seconds, and Milliseconds fields.
- Ctrl+K splits at the playhead.
- Alt+Enter opens exact times and item properties.

PROJECT COMMANDS

- Ctrl+N starts a new optional project.
- Ctrl+Shift+O opens an AMEPROJECT file.
- Ctrl+S saves the current project.
- Ctrl+Shift+S opens Save Project As.

NOT IMPLEMENTED YET

- Saving a trimmed clip as a new media file.
- Converting to another media format.
- Playing all project items continuously.
- Mixing narration, music, and original audio.
- Rendering transitions.
- Exporting a complete project as MP4.

The Export Edited Media button is intentionally disabled. It does not claim that rendering is available before the media engine exists.
