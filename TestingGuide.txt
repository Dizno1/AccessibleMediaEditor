ACCESSIBLE MEDIA EDITOR BUILD 0.11.2 RECOVERY TESTING GUIDE

STARTUP RECOVERY TEST

1. Install and start Accessible Media Editor.
2. Confirm JAWS reaches the Accessible Media Editor interface, Media Editor tab panel, Media region, and Open Media.
3. Stop immediately and report the result if the application remains on about:blank.

SCREEN-READER EXPORT CONVERSATION TEST

1. Cause any recognizable editing status message before export, such as a canceled paste.
2. Press Ctrl+E, select WebM, and activate Continue to Save.
3. Confirm the old editing message, Main region, Media Editor TabPanel, and Primary Production are not reread.
4. Confirm every production item, joining, track replacement, applying, and Primary Production rendered announcement is spoken once and in order. Rapid FFmpeg stages must queue instead of interrupting one another.
5. Choose the destination filename in the Windows Save dialog.
6. Confirm no delayed rendering announcement is spoken while the Save dialog is open or after the destination is chosen.
7. Confirm conversion start is announced.
8. If conversion lasts longer than one minute, confirm one elapsed-time update is spoken per minute.
9. Confirm Export Complete is presented only after finalization and no rendering or Finalizing message follows it.
10. Confirm focus lands directly on Show Saved File and the complete saved path is available from the dialog description.

ATOMIC EXPORT SAFETY TEST

1. Create a production long enough that WebM conversion takes noticeable time.
2. Press Ctrl+E, choose WebM, and select the destination filename.
3. Confirm JAWS announces that conversion is in progress and says to wait for Export Complete.
4. While conversion is running, inspect the destination folder. Confirm the requested final filename does not yet exist.
5. Confirm only a temporary filename containing ame-exporting may exist while conversion is running.
6. Do not use the file until the focused Export Complete dialog appears.
7. After Export Complete appears, confirm the requested final filename exists and the temporary filename is gone.
8. Open the completed file and confirm its duration matches Primary Production.
9. Repeat once and close the application during conversion. Confirm no incomplete file appears under the requested final filename.

ORDINARY INSERTION WITH CTRL+V

1. In a Source editor, set a recognizable selection and press Ctrl+C.
2. Return to Primary Production and make sure no brackets are set.
3. Move the Primary playhead to the desired insertion point and press Ctrl+V.
4. Confirm the copied selection is inserted, the original Primary material is preserved, and production duration increases.
5. Undo, place both Primary brackets at the same point so the selection is empty, and press Ctrl+V.
6. Confirm the same insertion occurs at that bracket point. Empty brackets must never replace or remove existing material.
7. Confirm Ctrl+Shift+V remains available as an optional explicit Insert command but is not required for ordinary insertion.

PRIMARY-CONTROLLED AUDIO REPLACEMENT

1. In Primary Production, press A. Confirm Audio Only is announced as the Primary replacement target.
2. Set a non-empty Primary range with Left Bracket and Right Bracket.
3. Note the announced selection duration.
4. Move to a Source Audio or Source Video editor. Do not choose A, V, or B there.
5. Select matching-duration Source material and press Ctrl+C.
6. Return to Primary Production and press Ctrl+V.
7. Confirm only Primary audio inside the selected range is replaced by Source audio.
8. Confirm the existing Primary video continues unchanged and production duration does not change.
9. Press Ctrl+Z and confirm the original audio returns. Press Ctrl+Y and confirm the replacement returns.

PRIMARY-CONTROLLED VIDEO REPLACEMENT

1. In Primary Production, press V. Confirm Video Only is announced as the Primary replacement target.
2. Set a non-empty Primary range with Left Bracket and Right Bracket.
3. In a Source Video editor, select matching-duration material and press Ctrl+C. Do not choose a Source target.
4. Return to Primary Production and press Ctrl+V.
5. Confirm only Primary video inside the selected range is replaced by Source video.
6. Confirm the existing Primary audio continues unchanged and production duration does not change.

BOTH-TRACK REPLACEMENT

1. In Primary Production, press B and select a non-empty range.
2. In a Source Video editor, select matching-duration material and press Ctrl+C.
3. Return to Primary Production and press Ctrl+V.
4. Confirm both picture and sound are replaced only inside the selected Primary range.
5. Confirm production duration does not change.

REPLACEMENT PROTECTION

1. Select a non-empty range in Primary Production.
2. Copy a Source selection that is longer than the Primary range.
3. Return to Primary Production and press Ctrl+V.
4. Confirm Paste is canceled and JAWS announces the copied duration, destination duration, and difference.
5. Confirm no Source material is truncated and no Primary material is changed.
6. Set inward Primary brackets that select two separate ranges and press Ctrl+V.
7. Confirm replacement is rejected because replacement requires one continuous Primary range.

SOURCE TARGET SCOPE

1. Enter any Source editor and press A, V, or B.
2. Confirm the application explains that replacement targeting is chosen in Primary Production.
3. Confirm the Source playhead and Source brackets remain unchanged.
4. Confirm Copy announces the selected duration and Source name without attaching a track target to the copied material.

EXPORT LOCATION TEST

1. Press Ctrl+E, choose a format, and continue to the Windows Save dialog.
2. Save the production.
3. Confirm a focused Export Complete dialog reads the complete verified saved path.
4. Activate Show Saved File and confirm File Explorer opens the actual containing folder with the exported file selected.
5. Confirm canceling the Save dialog announces Save canceled and does not announce success.

COMPLETE PRODUCTION EXPORT TEST

1. Open one video as Primary and at least two different video or audio files as Sources.
2. Copy short selections from the Sources and paste them at clearly identifiable Primary playhead positions.
3. Play Primary Production and confirm the complete sequence order before exporting.
4. Press Ctrl+E and choose MP4 video.
5. Confirm progress identifies each production item and then announces the final join.
6. Choose a filename and location in the Windows Save dialog.
7. Confirm Complete production saved is announced.
8. Open the saved file outside Accessible Media Editor.
9. Confirm every item is present in the expected order, all edits are applied, audio is audible, and the saved duration matches Primary Production.
10. Repeat with an audio format and confirm the complete production audio is exported.
11. Confirm every original source file remains unchanged.

COMPLETE SELECTION AUDITION TEST

1. In a Source editor, set an outward Left and Right Bracket selection lasting several seconds.
2. Press Space once. Confirm the complete selection plays from its first bracket through its second bracket.
3. Confirm playback stops at the selection boundary and the playhead returns to its original location.
4. Press Ctrl+C and confirm the copied duration matches the duration you just auditioned.
5. Set inward brackets and press Space. Confirm both selected ends play in timeline order and the unselected middle is skipped.
6. Press Escape to clear the brackets.
7. Move to the middle of the media and press Space. Confirm playback continues from that playhead rather than stopping after a short sample.
8. Press Space again. Confirm audition stops and returns to the original playhead.
9. Confirm X still performs ordinary Play/Pause and U/I still perform short scrub samples.

AUDIBLE SCRUB TEST

1. Open media containing clear speech or music and enter Primary Production with the Virtual Cursor off.
2. Press X, allow the media to play for several seconds, and press X again.
3. Press U and I separately. Confirm each command moves one second and plays an audible 500-millisecond sample from the new playhead position.
4. Press Shift+U and Shift+I. Confirm each command moves 100 milliseconds and plays the sample.
5. Press Ctrl+Alt+U and Ctrl+Alt+I. Confirm each command moves 10 milliseconds and plays the sample.
6. Confirm JAWS does not speak Auditioning, Returned, or Playhead over any scrub sample.
7. Repeat the test in one Source editor.

COMPLETED BRACKET CLEANUP TEST

1. In a Source editor, set brackets and press Ctrl+C.
2. Confirm the selection is copied and its brackets are cleared.
3. Move to Primary Production, set one or two brackets, and press Ctrl+V.
4. Confirm the selection is pasted and the old Primary brackets are cleared.
5. Immediately press Ctrl+Z. Confirm the Paste is undone, rather than hearing that an old bracket was removed.
6. Create a bracket selection and press Ctrl+Delete.
7. Confirm the edit is applied and its brackets are cleared.
8. Immediately press Ctrl+Z. Confirm the deleted media is restored.
9. Set an unfinished bracket and press Escape. Confirm the unfinished bracket is canceled without changing media.
10. Reassign a Source as Primary and confirm brackets from the old arrangement do not remain.

FIRST IMPORT REGRESSION TEST

1. Start with no media open.
2. Press Ctrl+O and choose one Primary video.
3. Confirm Loading selected media. Please wait is announced.
4. Confirm the Primary video remains Primary and does not become Source media.
5. Confirm no TypeError is announced.
6. If an import fails, confirm the entire import is rolled back and the previous editing session remains intact.

PRIMARY REAL EDIT TEST

1. Open one video as Primary Media.
2. Turn the JAWS Virtual Cursor off with Insert+Z.
3. Enter the Primary editor.
4. Move to the beginning of a short unwanted section and press left bracket.
5. Move to the end of the unwanted section and press right bracket.
6. Press Ctrl+Delete.
7. Confirm Edit applied and the shorter duration are announced.
8. Press Home and then X. Confirm playback skips the removed section immediately without export.
9. Use U, I, Left Arrow, Right Arrow, Home, End, and the playhead. Confirm all use the shorter edited timeline.
10. Press Ctrl+Z. Confirm the removed media is restored.
11. Repeat the edit and wait for Edited working file ready.
12. Press Ctrl+E and save the edited file.
13. Open the saved file outside the editor and confirm the section is physically absent.
14. Confirm the original file is unchanged.

SINGLE BRACKET LOGIC TEST

1. Open one video as Primary Media.
2. Move to the desired new ending and press left bracket only.
3. Press Ctrl+Delete.
4. Confirm everything to the right of the Left Bracket is deleted and the content to its left remains.
5. Press Ctrl+Z and confirm the ending returns.
6. Move to the desired new beginning and press right bracket only.
7. Press Ctrl+Delete.
8. Confirm everything to the left of the Right Bracket is deleted and the content to its right remains.
9. Press Ctrl+Z and confirm the beginning returns.
10. Set the Left Bracket at an earlier time and the Right Bracket at a later time.
11. Confirm Outward brackets and the selected content are announced without calling it deletable data.
12. Press Ctrl+Delete and confirm only the content between the outward-facing brackets is deleted.
13. Press Ctrl+Z and confirm the content returns.
14. Move to a desired clip beginning and set the Right Bracket.
15. Continue forward and set the Left Bracket at the desired clip ending.
16. Confirm Inward brackets announce that the beginning and end are selected and the middle is not selected.
17. Press Ctrl+Delete and confirm the selected beginning and end are deleted, leaving the unselected middle.
18. Press Ctrl+Z once and confirm both deleted ends return.
19. Press Ctrl+Y once and confirm both ends are deleted again.

CHANGE PRIMARY PRODUCTION TEST

1. Import several files at once.
2. In Source Media, select the file that should be Primary.
3. Activate Make Selected Source Primary.
4. Confirm the selected filename is announced as Primary Production.
5. Confirm the former Primary is announced as moved to Source Media.
6. Confirm the new Primary plays in the unified Primary Production editor.
7. Confirm the former Primary has its own Source editor and retains its edits.
8. Press Ctrl+Z once and confirm the original Primary and Source roles return.
9. Press Ctrl+Y once and confirm the swap is reapplied.
10. Repeat the command through Project, Make Selected Source Primary.

SOURCE COPY AND PRIMARY INSERT TEST

1. Open a second supported video as Source Media.
2. Enter its Source editor.
3. Move to the desired selection beginning and press left bracket.
4. Confirm Left Bracket and the selected area are announced.
5. Move to the desired selection ending and press right bracket.
6. Confirm Right Bracket and the enclosed selection are announced.
7. Press Ctrl+C and confirm the filename, copied duration, and cleared brackets are announced.
8. Set the Source brackets again, use Edit, Copy Source Selection, and confirm it performs the same command.
9. Create an inward selection by setting Right Bracket earlier and Left Bracket later. Press Ctrl+C and use Ctrl+Shift+V in Primary Production. Confirm both selected ends are copied in their original order and the unselected middle is not copied.
10. Press Ctrl+Page Up until Primary Production is focused.
11. Move its playhead to the desired insertion point and press Ctrl+Shift+V.
12. Confirm the inserted duration and insertion time are announced.
13. Move to another Primary position, use Edit, Paste Insert into Sequence, and confirm it performs the same command.
14. Press Home and X. Confirm Primary Production plays continuously through the original and pasted media.
14. Confirm no separate Inserted Video editor region was created.
15. Press Ctrl+Z and confirm the inserted material is removed from Primary Production.
16. Confirm the complete original Source file remains available and unchanged.

SOURCE REMOVAL TEST

1. Enter a Source editor and activate Remove Source from Project.
2. Confirm Source removed. Press Ctrl+Z to restore it. Original file unchanged is announced.
3. Confirm focus moves to the next Source editor, or to Primary Production if no Source remains.
4. Press Ctrl+Z once and confirm Source restored is announced, the Source editor returns, and focus returns to it.

SOURCE NONDESTRUCTIVE EDIT TEST

1. Enter a Source Video or Source Audio editor.
2. Set a lone Right Bracket and press Ctrl+Delete.
3. Confirm the beginning is deleted from immediate Source playback.
4. Confirm Activate Primary Production first is not announced.
5. Press Home and X and confirm playback begins at the edited Source beginning.
6. Set brackets around material in the edited Source and press Ctrl+C.
7. Use Ctrl+Shift+V to insert into Primary Production and confirm the copied material comes from the edited Source timeline.
8. Confirm the original Source file remains unchanged.

EDITED SOURCE PLAYHEAD ACCURACY TEST

1. Delete several seconds from the beginning of a Source.
2. Press Home and X to begin playback of the edited Source.
3. When you hear a recognizable word, press X to pause.
4. Press Space and confirm the audition contains that same word or the immediately surrounding audio.
5. Press X twice several times and confirm each pause remains at the point actually heard rather than jumping forward.
6. Press Space and immediately press a bracket before the sample finishes. Confirm the bracket uses the original audition point rather than a later moving playback position.
7. Apply an edit with Ctrl+Delete, press Ctrl+Z once, and confirm the deleted material returns.
8. Press Ctrl+Y once and confirm the edit is reapplied.

PAUSE AND BRACKET SYNCHRONIZATION TEST

1. Enter Primary Production and press X to play.
2. Press X to pause and listen to the announced time.
3. Immediately press Left Bracket or Right Bracket.
4. Confirm the bracket time exactly matches the paused time.
5. Repeat in at least two Source editors.
6. Repeat after deleting part of Primary Production and after deleting part of a Source.
7. Confirm no delayed media event moves the paused playhead after X announces its position.

PRECISION SCRUBBING TEST

1. With the Virtual Cursor off, enter Primary Production or a Source editor.
2. Press U and I and confirm movement by 1 second with a short quiet media sample.
3. Press Shift+U and Shift+I and confirm movement by 100 milliseconds.
4. Press Ctrl+Alt+U and Ctrl+Alt+I and confirm movement by 10 milliseconds.
5. Press Alt+Left Arrow and Alt+Right Arrow and confirm movement by 1 millisecond.
6. Confirm Ctrl+Alt+I does not open Chromium Developer Tools.
7. Confirm scrubbing does not speak a status message over the media sample.

QUIET INTERACTION TEST

1. Arrow through Primary Sequence and Source Media.
2. Confirm JAWS reads only the short list option and does not append the detailed duration paragraph.
3. Tab within an editor.
4. Confirm there is one custom Play or Pause button and one custom playhead slider. The native video buttons and second scrubber should not appear.
5. Use X, Space, U, I, Home, End, and movement keys.
6. Confirm filenames are not repeated in routine transport announcements.
7. Press U or I rapidly and confirm no AbortError is announced.
8. Press Space, U, and I and confirm JAWS does not say Auditioning or Returned over the media sample.

FORMAT CONVERSION TEST

1. Open a WMV file.
2. Confirm the application announces that it is converting the media and asks you to wait.
3. Confirm Media ready or the normal loaded-duration message is announced after conversion.
4. Enter the editor and confirm the WMV content now plays from its normalized working copy.
5. Confirm the original WMV file remains unchanged.

SOURCE MARK AND NAVIGATION TEST

1. Open a second file as Source Media and enter its editor.
2. Move several seconds forward and press Left Bracket.
3. Press Home and confirm the playhead returns to 0 rather than the Selection Start.
4. Press End and confirm the playhead moves to the full Source duration.
5. Set another mark and press Ctrl+Z. Confirm the most recent uncommitted mark is removed.
6. Set one or two marks and press Escape. Confirm all uncommitted marks are canceled.

KNOWN LIMITS

Every imported video or audio file is converted to an app-owned working format before editing. Large files may require significant conversion time. Progress percentages are not included yet.

Build 0.10.0 renders sequential video and audio items plus A, V, and B track replacements into one file. Text, image, and transition items are not rendered yet and must be removed before export.

AudioStudio Pro recording and processing are not implemented in this build.
