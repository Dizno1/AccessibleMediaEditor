ACCESSIBLE MEDIA EDITOR BUILD 0.2.2 TESTING GUIDE

WHAT THIS BUILD CAN DO

- Import one or several video, audio, or image files.
- Paste several copied File Explorer files into the Import Media dialog.
- Preview one selected video or audio item at a time.
- Move project items earlier or later.
- Set nondestructive In and Out points.
- Enter exact times with Hours, Minutes, Seconds, and Milliseconds fields.
- Move the playhead by one millisecond.
- Split a selected video or audio item at the playhead.
- Save and reopen an Accessible Media Editor project.

WHAT THIS BUILD CANNOT DO YET

- Play all project items continuously.
- Delete a selected section from within a clip.
- Mix narration, music, and original audio.
- Render transitions.
- Export the completed project as an MP4.

JAWS VIRTUAL CURSOR WORKFLOW

Reading the workspace:
Leave the Virtual Cursor on.

Selecting a project item:
1. Leave the Virtual Cursor on while navigating to Project Items.
2. Position JAWS inside the Project Items list box.
3. Press Insert+Z to turn the Virtual Cursor off while focus is inside the list box.
4. Press plain Up Arrow or Down Arrow to select another item.
5. Do not hold Ctrl when selecting another item.

Moving a project item:
1. Keep focus inside Project Items with the Virtual Cursor off.
2. Press Ctrl+Up Arrow to move the selected item earlier.
3. Press Ctrl+Down Arrow to move the selected item later.

Using the playhead:
1. Position JAWS on the Playhead slider.
2. Turn the Virtual Cursor off.
3. Use Left Arrow or Right Arrow to change its position.
4. Use Alt+Left Arrow or Alt+Right Arrow to move by one millisecond.

Setting precise edits:
- I sets the In point at the playhead.
- O sets the Out point at the playhead.
- Ctrl+G opens separately labeled Hours, Minutes, Seconds, and Milliseconds fields.
- Ctrl+K splits the selected item at the playhead.
- Alt+Enter opens Item Properties.

Returning to normal reading:
Press Insert+Z to turn the Virtual Cursor on again.

Windows file dialogs:
The JAWS Virtual Cursor setting does not apply inside native Import, Open, or Save dialogs.

SHORTCUTS BY TASK

Projects and media:
- Ctrl+N: New project.
- Ctrl+O: Open a saved AMEPROJECT file.
- Ctrl+S: Save.
- Ctrl+Shift+S: Save As.
- Ctrl+I: Import media.

Selecting and arranging:
- Plain Up Arrow or Down Arrow: Select another project item when focus is inside the list box.
- Ctrl+Up Arrow: Move the selected item earlier.
- Ctrl+Down Arrow: Move the selected item later.
- Delete: Remove the selected item.

Playback and editing:
- Ctrl+P: Preview the selected item.
- Escape: Stop playback or close an editing dialog.
- I: Set the In point.
- O: Set the Out point.
- Alt+Left Arrow or Alt+Right Arrow: Move the playhead by one millisecond.
- Ctrl+G: Go to an exact human-readable time.
- Ctrl+K: Split at the playhead.
- Alt+Enter: Open Item Properties.

FIRST TEST

1. Import two short video clips.
2. Enter Project Items and turn the Virtual Cursor off there.
3. Use plain Arrow keys to confirm that the two different filenames are present.
4. Select the first clip and press Ctrl+P.
5. Stop with Escape.
6. Select the second clip and confirm that its playhead begins at its In point.
7. Preview the second clip.
8. Confirm that Out point reached is announced only once.
