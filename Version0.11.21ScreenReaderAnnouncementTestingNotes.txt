Accessible Media Editor Build 0.11.21

This build reduces unnecessary screen reader speech in the Presentation workspace.

Changes to test:

1. Enter the Presentation Timeline. JAWS should announce the concise list name, the current item, and its position. It should not repeat embedded keyboard instructions or a second live-region description.

2. Enter the Source Media Library. JAWS should announce the concise list name and current item without a paragraph of instructions.

3. Delete one or more selected Presentation Timeline items. The removal should occur once and produce one result announcement. It should not first say that no items are selected.

4. Open and close the Background music audio source combo box with Escape. Escape should close the native list without also announcing No temporary operation to cancel.

5. Activate Preview Complete Presentation. Rendering progress should be announced. The Preview dialog should open only after the media player has loaded enough information to be available. Tabbing to the native Play button should continue to work.

6. Standard JAWS control hints, such as To activate press Spacebar, are generated by JAWS and remain unchanged.
